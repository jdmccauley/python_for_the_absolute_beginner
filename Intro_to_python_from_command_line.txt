To begin, this is how to enter a python3 interactive environment from commmand line:
python3
The python3 interactive environment lets you test python code in real time.
To run scripts however, it is easiest to switch back to bash.

Within python3, this is how you check your current directory:
import os
os.getcwd()
To change your directory, you can do this:
os.chdir('directory_of_interest')
To make a new directory, use the following command:
os.mkdir(path_to_new_directory_name)
Otherwise, if path not written the new directory is made in the current directory if
the new directory name is written in quotes like the following:
os.mkdir('new_directory_name')
To go one directory down, use the following command:
os.chdir('../')

To exit python3 back to bash in command line, use the following command:
exit()
