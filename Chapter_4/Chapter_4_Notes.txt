Loops, again
While loops repeat themselves based on an assessment of a condition.
For loops on the other hand, repeat themselves based on a sequence until the sequence ends.
So in other words, a loop runs until the sequence (or list) is complete, and the while
	loop runs until the condition is TRUE.
For loops 'iterate' over each 'element' in a 'sequence'.
For loop format:
	for [element] in [sequence]:
		code
Note that when making a for loop, it is not necessary to initialize the counter variable.
	Python will already do it.

The range() function is a great way to make a 'sequence' to be used in a for loop.
You can make range() run in the following way:
	range([start], [stop], [step])
	The range can be sequence, for example:
	for i in range(0,10,1):
		print(i)
		i += 1
I wrote counter.py to show this.
Note that when using range() in a for loop, the final iteration is [stop] -1,
	because once the counter reaches the [stop] value, the loop is FALSE.
The [step] argument in the 'range()' function is not always needed if the counter is
	modified in the loop code. It makes no difference whether to modify the counter with
	the step argument or in the loop itself.

Strings and position numbers, Indexing
A string can be thought of as an array of characters, with each character having a position in the array.
For example, the string:
quote = joshuamccauley
Can be accessed one character at a time.
quote[0] -> j
quote[3] -> h
What's important to know is that strings also have negative positions, which are just the string backwards.
quote[-1] -> y
quote[-3] -> l
Each position can be referred to as an index of the string.
I wrote a program quote_sampler.py to showcase how the string positions work.

Mutability
Variables that are mutable are those that can be modified after an assignment. For example, this array is mutable because the following can work:
my_array = [0, 1, 2, 3, 4]
my_array[1] = 6
my_array[1] -> 6
However, strings are immutable. They can be re-declared, but they cannot be modified (mutated).
string = "This is a test."
string[0] = "x" -> error
However, if you make a string a list, it can work (more on lists later though):
string = "This is a test."
string_list = list(string)
string_list[0] = "x"
string_list -> "xhis is a test."
Now you could redeclare the string as the new list if desired.
	It may be easier to just change the string explicitly by declaring it again in many cases. If not possible to declare every time, changing to a list do modify is a good idea.
Note: you can parse strings to check if characters are in the string with a for loop.
	For example, you can use a loop to check
		for letter in [string]:
			if letter not in [string_2]:
				[string_2] += letter
	Note that when comparing strings, you must make sure that the cases are the same.

Slicing
Note that you can access each character at a time by calling its index (or negative index), or range of indexes.
You can use this 'slice' to make modifications to other strings if desired.
I'll write a program named sentense_slicer.py to show how slices work.
The end index of a slice specifies where to stop before.
So the following
	quote = "test"
	print(quote[1:3]) -> "es"
is true because "es" is from index 1 to 2, before index 3.
Important to note: not having a beginning index assumes zero.
	print(quote[:3]) -> tes
Also, just a colon in the brackets returns the whole sequence.
Stepping can be added at the end of the slicing:
string[start:end:step]
	Default is +1.
	To go backwards, just use: string[0:len(string):-1]
	Or better yet, just do: string[::-1]

Tuples
In python, a tuple is an object that can contain multiple elements that may not all be the same type.
For all intents and purposes, tuples are like arrays in some other languages.
Tuples are declared like lists, but with "()" instead of "[]".
The important difference between tuples and lists is that lists are mutable, tuples are immutable.
Note that empty tuples (and strings for that matter) are false when empty.
For the following program:
	[tuple or list] = None
	if [tuple or list]:
		print("True")
	else:
		print("False")
The return would be "False".
Tuples can be indexed, sliced, and concatenated.
You can use the "in" operator to test if an element is contained in the tuple. It's easy to use this to see
	if elements are contained in the list.
When parsing through a tuple (or list), you can just call the index when doing an action on it.
For example, this is a program and its output:
	tuple = ("this", "is", "a", "test")
	for i in tuple:
		print(i)
output:
	this
	is
	a
	test
